## Implementation

### Part 1: CSV Export (AnalysisResultsDisplay.tsx)

Pure client-side — no backend needed:

```typescript
const exportCSV = () => {
  if (!results) return
  const headers = [
    'Gene Symbol', 'Gene ID', 'N Datasets', 'Avg Hazard Ratio',
    'Avg Cox P-Value', 'Direction Consistency %', 'Risk Direction', 'Datasets'
  ]
  const rows = results.common_genes.map(g => [
    g.gene_symbol,
    g.gene_id,
    g.n_datasets,
    g.avg_hazard_ratio.toFixed(4),
    g.avg_cox_p_value.toExponential(3),
    (g.risk_direction_consistency * 100).toFixed(1),
    g.avg_hazard_ratio > 1 ? 'High Risk' : 'Protective',
    // escape commas in dataset IDs with quotes
    `"${g.datasets.map(d => d.dataset_id).join('; ')}"`
  ])
  const csv = [headers.join(','), ...rows.map(r => r.join(','))].join('\n')
  const blob = new Blob([csv], { type: 'text/csv;charset=utf-8;' })
  const link = document.createElement('a')
  link.href = URL.createObjectURL(blob)
  const safeQuery = results.query.replace(/[^a-zA-Z0-9]/g, '_').slice(0, 30)
  link.download = `geo_survival_${safeQuery}_${new Date().toISOString().slice(0,10)}.csv`
  document.body.appendChild(link)
  link.click()
  document.body.removeChild(link)
  URL.revokeObjectURL(link.href)
}
```

### Part 2: PNG Export for Volcano Plot

Install dependency:
```bash
cd frontend && npm install html2canvas @types/html2canvas
```

```typescript
import html2canvas from 'html2canvas'
const volcanoRef = useRef<HTMLDivElement>(null)

const exportPNG = async () => {
  if (!volcanoRef.current) return
  const canvas = await html2canvas(volcanoRef.current, {
    backgroundColor: '#ffffff',
    scale: 2  // 2x for higher resolution
  })
  const link = document.createElement('a')
  link.download = `volcano_plot_${new Date().toISOString().slice(0,10)}.png`
  link.href = canvas.toDataURL('image/png')
  link.click()
}
```

Wrap the volcano chart div: `<div ref={volcanoRef}>..volcano chart..</div>`
