# F06 — Enable Chat Streaming

**Size**: M | **Priority**: 6

## Problem

`chatApi.ts` hardcodes `stream: false`. Backend SSE chat streaming is fully implemented in `chat_routes.py`. LangChain streaming in `langchain_service.py` is done. Chat freezes 15–30 seconds during tool calls — undercuts the conversational experience.

## Files to Read First

- `frontend/src/services/chatApi.ts` (find `stream: false`)
- `backend/app/api/chat_routes.py` (lines 280–320 — understand SSE format and event types)

- `frontend/src/components/chat/MessageList.tsx` (how messages render)

## Implementation

### Frontend: chatApi.ts

Replace the `axios.post` call in `sendMessage` with `fetch` + `ReadableStream`:

```typescript
export const sendMessageStreaming = async (
  conversationId: string,
  content: string,
  model: string,
  token: string,
  onChunk: (text: string) => void,
  onComplete: (message: MessageResponse) => void,
  onError: (err: string) => void
): Promise<void> => {
  const response = await fetch(`/api/chat/conversations/${conversationId}/messages`, {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'Authorization': `Bearer ${token}`
    },
    body: JSON.stringify({ content, model, stream: true })
  })
  if (!response.ok) {
    onError(`HTTP ${response.status}: ${await response.text()}`)
    return
  }
  const reader = response.body!.getReader()
  const decoder = new TextDecoder()
  let buffer = ''
  while (true) {
    const { done, value } = await reader.read()
    if (done) break
    buffer += decoder.decode(value, { stream: true })
    const lines = buffer.split('\n')
    buffer = lines.pop() ?? ''
    for (const line of lines) {
      if (!line.startsWith('data: ')) continue
      try {
        const event = JSON.parse(line.slice(6))
        if (event.type === 'token') onChunk(event.content)
        else if (event.type === 'message_complete') onComplete(event.message)
        else if (event.type === 'error') onError(event.message)
      } catch {
        // skip malformed events
      }
    }
  }
}
```

### Frontend: chatSlice.ts

Add streaming state:
```typescript
// Add to ChatState:
streamingContent: string
isStreaming: boolean

// Add reducers:
appendStreamingChunk(state, action: PayloadAction<string>) {
  state.streamingContent += action.payload
  state.isStreaming = true
},
finalizeStreaming(state, action: PayloadAction<Message>) {
  state.streamingContent = ''
  state.isStreaming = false
  // add the completed message to messages array
  if (state.activeConversation) {
    state.messages.push(action.payload)
  }
},
clearStreaming(state) {
  state.streamingContent = ''
  state.isStreaming = false
},
```

Update `sendMessage` thunk to use `sendMessageStreaming`:
```typescript
// Instead of the axios call, use:
await sendMessageStreaming(
  conversationId, content, model, token,
  (chunk) => dispatch(appendStreamingChunk(chunk)),
  (message) => dispatch(finalizeStreaming(mapToMessage(message))),
  (err) => dispatch(setError(err))
)
```
