# F02 — Gene Search, Filter, and Pagination

**Size**: S | **Priority**: 2

## Problem

`AnalysisResultsDisplay.tsx` renders all genes with `sortedGenes.map(...)` into the DOM — no filtering, no search, no pagination. Analyses returning 500–1000+ genes are unusable.

## Files to Read First

- `frontend/src/components/chat/AnalysisResultsDisplay.tsx` (full file — find the Genes tab section)
- `frontend/src/store/chatSlice.ts` (search for `GeneSurvival` to understand gene data shape)

## Implementation

All changes in `AnalysisResultsDisplay.tsx` (Genes tab section only):

**1. Add state hooks** (near top of component):
```tsx
const [geneFilter, setGeneFilter] = useState('')
const [sortField, setSortField] = useState<'n_datasets' | 'avg_hazard_ratio' | 'avg_cox_p_value' | 'consistency'>('n_datasets')
const [sortDir, setSortDir] = useState<'asc' | 'desc'>('desc')
const [page, setPage] = useState(0)
const PAGE_SIZE = 50
```

**2. Derive filtered + sorted + paginated list**:
```tsx
const filteredGenes = useMemo(() => {
  let genes = [...(results?.common_genes ?? [])]
  if (geneFilter) {
    genes = genes.filter(g =>
      g.gene_symbol.toLowerCase().includes(geneFilter.toLowerCase())
    )
  }
  genes.sort((a, b) => {
    const aVal = sortField === 'consistency' ? a.risk_direction_consistency
      : sortField === 'avg_cox_p_value' ? a.avg_cox_p_value
      : sortField === 'avg_hazard_ratio' ? a.avg_hazard_ratio
      : a.n_datasets
    const bVal = sortField === 'consistency' ? b.risk_direction_consistency
      : sortField === 'avg_cox_p_value' ? b.avg_cox_p_value
      : sortField === 'avg_hazard_ratio' ? b.avg_hazard_ratio
      : b.n_datasets
    return sortDir === 'desc' ? bVal - aVal : aVal - bVal
  })
  return genes
}, [results?.common_genes, geneFilter, sortField, sortDir])

const pageGenes = filteredGenes.slice(page * PAGE_SIZE, (page + 1) * PAGE_SIZE)
const totalPages = Math.ceil(filteredGenes.length / PAGE_SIZE)
```

**3. Reset page on filter change**:
```tsx
useEffect(() => setPage(0), [geneFilter])
```

**4. Add search input above gene list**:
```tsx
<div className="flex items-center gap-2 mb-3">
  <input
    type="text"
    placeholder="Search genes..."
    value={geneFilter}
    onChange={e => setGeneFilter(e.target.value)}
    className="flex-1 border border-gray-300 rounded px-2 py-1 text-sm focus:outline-none focus:ring-1 focus:ring-blue-500"
  />
  <span className="text-xs text-gray-500 whitespace-nowrap">
    {filteredGenes.length} of {results?.common_genes?.length ?? 0}
  </span>
</div>
```

**5. Add sort header row** above gene list items (click to toggle):
```tsx
<div className="flex text-xs text-gray-500 font-medium border-b pb-1 mb-1">
  <span className="flex-1">Gene</span>
  {(['n_datasets', 'avg_hazard_ratio', 'avg_cox_p_value', 'consistency'] as const).map(field => (
    <button key={field} onClick={() => {
      if (sortField === field) setSortDir(d => d === 'asc' ? 'desc' : 'asc')
      else { setSortField(field); setSortDir('desc') }
    }} className="w-20 text-right hover:text-gray-700">
      {field === 'n_datasets' ? 'Datasets' : field === 'avg_hazard_ratio' ? 'HR'
        : field === 'avg_cox_p_value' ? 'P-value' : 'Consist.'}
      {sortField === field && (sortDir === 'desc' ? ' ↓' : ' ↑')}
    </button>
  ))}
</div>
```

**6. Render `pageGenes` instead of `sortedGenes`**

**7. Add pagination controls** below gene list:
```tsx
{totalPages > 1 && (
  <div className="flex items-center justify-center gap-3 mt-3 text-sm text-gray-600">
    <button disabled={page === 0} onClick={() => setPage(p => p - 1)}
      className="px-2 py-1 border rounded disabled:opacity-40 hover:bg-gray-50">
      ← Prev
    </button>
    <span>Page {page + 1} of {totalPages}</span>
    <button disabled={page >= totalPages - 1} onClick={() => setPage(p => p + 1)}
      className="px-2 py-1 border rounded disabled:opacity-40 hover:bg-gray-50">
      Next →
    </button>
  </div>
)}
```
