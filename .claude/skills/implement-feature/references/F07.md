# F07 — Persist Analysis Results to Database

**Size**: M | **Priority**: 7 | **Unlocks**: F09, F12, F14, F15

## Problem

Results live only in Redux state. Navigate away, refresh, or open another tab — results are gone. Prerequisite for shareable URLs, analysis history, comparison mode, and export packages.

## Implementation

### Backend: New Database Model

`backend/app/models/database.py` — Add `AnalysisResult` class (follow exact same pattern as existing models):
```python
import uuid as uuid_module
from sqlalchemy.dialects.postgresql import UUID, JSONB

class AnalysisResult(Base):
    __tablename__ = "analysis_results"

    id = Column(UUID(as_uuid=True), primary_key=True, default=uuid_module.uuid4)
    user_id = Column(UUID(as_uuid=True), ForeignKey("users.id", ondelete="CASCADE"),
                     nullable=True, index=True)
    conversation_id = Column(UUID(as_uuid=True), ForeignKey("conversations.id", ondelete="SET NULL"),
                             nullable=True)
    query = Column(Text, nullable=False)
    result_json = Column(JSONB, nullable=False)
    n_datasets_analyzed = Column(Integer, nullable=False, default=0)
    n_genes_found = Column(Integer, nullable=False, default=0)
    processing_time_seconds = Column(Float, nullable=True)
    created_at = Column(DateTime(timezone=True), server_default=func.now(),
                        nullable=False, index=True)
```

### Backend: Save on Search

`backend/app/api/routes.py` — In the `/api/search` endpoint, after `result = await orchestrator.analyze_query(...)`:
```python
# Save to database (optional — don't fail if DB unavailable)
try:
    async with get_async_session() as session:
        analysis_record = AnalysisResult(
            user_id=current_user.id if current_user else None,
            query=request.query,
            result_json=result.model_dump(),
            n_datasets_analyzed=result.n_datasets_analyzed,
            n_genes_found=len(result.common_genes),
            processing_time_seconds=result.processing_time_seconds
        )
        session.add(analysis_record)
        await session.commit()
        result.result_id = str(analysis_record.id)
except Exception as e:
    logger.warning(f"Failed to persist analysis result: {e}")
    # Don't fail the request if DB save fails
```

### Backend: New Endpoints

`backend/app/api/routes.py`:
```python
@router.get("/api/analysis/{result_id}")
async def get_analysis(
    result_id: str,
    current_user = Depends(get_current_user_optional)
):
    async with get_async_session() as session:
        result = await session.get(AnalysisResult, uuid_module.UUID(result_id))
        if not result:
            raise HTTPException(status_code=404, detail="Analysis not found")
        return result.result_json

@router.get("/api/analysis/history")
async def get_analysis_history(
    current_user = Depends(get_current_user),
    limit: int = 50,
    offset: int = 0
):
    async with get_async_session() as session:
        stmt = (
            select(AnalysisResult)
            .where(AnalysisResult.user_id == current_user.id)
            .order_by(AnalysisResult.created_at.desc())
            .limit(limit).offset(offset)
        )
        results = await session.execute(stmt)
        items = results.scalars().all()
        return [{"id": str(r.id), "query": r.query, "n_datasets": r.n_datasets_analyzed,
                 "n_genes": r.n_genes_found, "created_at": r.created_at.isoformat()}
                for r in items]
```
