# F13 — Multivariate Cox Regression with Clinical Covariates

**Size**: L | **Priority**: 13

## Problem

Univariate Cox regression is sufficient for discovery but insufficient for peer-reviewed publication. Reviewers reject survival analyses that don't adjust for known confounders (age, stage, treatment). This feature makes results publishable, not just exploratory.

## Files to Read First

- `backend/app/services/survival_analysis_service.py` (full file — find Cox fitting code and LLM metadata detection)
- `backend/app/models/response_models.py` (`GeneDatasetResult`, `GeneSurvivalResult`)
- `frontend/src/components/KaplanMeierPlot.tsx` (per-dataset statistics table)
- `frontend/src/store/chatSlice.ts` (`GeneDatasetResult` interface)

### Backend: Multivariate Cox Fitting

In the Cox regression section of `survival_analysis_service.py`:
```python
from lifelines import CoxPHFitter
import pandas as pd
import numpy as np

def _fit_cox_with_covariates(
    self,
    expression_col: pd.Series,
    time_col: pd.Series,
    event_col: pd.Series,
    metadata_df: pd.DataFrame,
    covariate_columns: list[str],
    categorical_covariates: list[str]
) -> tuple[float, float, float, float, list[str]]:
    """Returns: (unadj_hr, adjusted_hr, cox_pvalue, ci_lower, ci_upper, covariates_used)"""

    # Build base DataFrame
    cox_df = pd.DataFrame({
        'expression': expression_col,
        'time': time_col,
        'event': event_col
    })

    # Univariate (always compute):
    cph_uni = CoxPHFitter()
    try:
        cph_uni.fit(cox_df[['expression', 'time', 'event']], duration_col='time', event_col='event')
        uni_hr = float(np.exp(cph_uni.params_['expression']))
        uni_pvalue = float(cph_uni.summary.loc['expression', 'p'])
    except Exception as e:
        self.logger.warning(f"Univariate Cox failed: {e}")
        return None, None, None, None, None, []

    # Multivariate (if covariates available):
    covariates_used = []
    adj_hr = uni_hr  # default to univariate if multivariate fails

    valid_covariates = [c for c in covariate_columns if c in metadata_df.columns]
    if valid_covariates:
        try:
            covariate_df = metadata_df[valid_covariates].copy()
            # One-hot encode categorical covariates:
            cat_cols = [c for c in categorical_covariates if c in covariate_df.columns]
            if cat_cols:
                covariate_df = pd.get_dummies(covariate_df, columns=cat_cols, drop_first=True)
            # Drop columns with too many missing values:
            covariate_df = covariate_df.dropna(axis=1, thresh=int(0.7 * len(covariate_df)))
            # Align indices:
            combined = pd.concat([cox_df, covariate_df], axis=1).dropna()
            if len(combined) >= 20:  # need enough samples
                cph_multi = CoxPHFitter()
                cph_multi.fit(combined, duration_col='time', event_col='event')
                adj_hr = float(np.exp(cph_multi.params_['expression']))
                covariates_used = [c for c in covariate_df.columns if c in combined.columns and c not in ['time', 'event', 'expression']]
        except Exception as e:
            self.logger.warning(f"Multivariate Cox failed, using univariate: {e}")

    ci_lower = float(np.exp(cph_uni.confidence_intervals_.loc['expression', '95% lower-bound']))
    ci_upper = float(np.exp(cph_uni.confidence_intervals_.loc['expression', '95% upper-bound']))
    return uni_hr, adj_hr, uni_pvalue, ci_lower, ci_upper, covariates_used
```
