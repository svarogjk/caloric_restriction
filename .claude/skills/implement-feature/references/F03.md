# F03 — CI Bands on KM Curves

**Size**: S | **Priority**: 3

## Problem

`ci_lower` and `ci_upper` are fully computed in backend, stored in `KMCurveData` response models, typed in Redux, and transmitted to the frontend — but `KaplanMeierPlot.tsx` never renders them. CI visualization is required for any published KM curve.

## Files to Read First

- `frontend/src/components/KaplanMeierPlot.tsx` (full file — find how chart data is built)
- `frontend/src/store/chatSlice.ts` (search `ci_lower` to understand the data shape)

## Implementation

The chart data array is built from objects like `{ time, [datasetId + '_high']: number, [datasetId + '_low']: number }`.

**Extend each chart data point** to also include CI bounds:
```typescript
// When building the chart data array for each dataset:
{
  time: t,
  [`${datasetId}_high`]: survivalHigh[i],
  [`${datasetId}_low`]: survivalLow[i],
  // ADD these if CI data exists:
  [`${datasetId}_ci_upper_high`]: kmHigh.ci_upper?.[i] ?? null,
  [`${datasetId}_ci_lower_high`]: kmHigh.ci_lower?.[i] ?? null,
  [`${datasetId}_ci_upper_low`]: kmLow.ci_upper?.[i] ?? null,
  [`${datasetId}_ci_lower_low`]: kmLow.ci_lower?.[i] ?? null,
}
```

**Add CI `<Line>` elements** in the LineChart for each visible dataset (after the existing high/low lines):
```tsx
{/* CI band for high expression */}
{kmHigh?.ci_upper && (
  <Line
    key={`${datasetId}_ci_upper_high`}
    dataKey={`${datasetId}_ci_upper_high`}
    stroke={color} strokeOpacity={0.25} strokeDasharray="3 2"
    dot={false} activeDot={false} legendType="none" strokeWidth={1}
    connectNulls={false}
  />
)}
{kmHigh?.ci_lower && (
  <Line
    key={`${datasetId}_ci_lower_high`}
    dataKey={`${datasetId}_ci_lower_high`}
    stroke={color} strokeOpacity={0.25} strokeDasharray="3 2"
    dot={false} activeDot={false} legendType="none" strokeWidth={1}
    connectNulls={false}
  />
)}
// Same pattern for kmLow ci_upper and ci_lower
```

Only add CI lines when the CI data is not null. Check per-dataset: `const hasCI = !!(kmHigh?.ci_upper && kmHigh?.ci_lower)`.

Do NOT add CI lines to the Recharts `<Legend>` — use `legendType="none"` on CI lines.
