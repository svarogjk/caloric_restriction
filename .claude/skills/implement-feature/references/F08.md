# F08 — Forest Plot Tab

**Size**: M | **Priority**: 8

## Problem

The app's unique value is cross-dataset meta-analysis. Forest plots are the universally-recognized visualization for meta-analysis. All per-dataset HR + CI data already exists in `GeneDatasetResult`. No competitor can show this because none do true multi-dataset analysis.

## Files to Read First

- `frontend/src/components/chat/AnalysisResultsDisplay.tsx` (full file — understand tab structure and how `common_genes` data is structured)
- `frontend/src/store/chatSlice.ts` (find `GeneDatasetResult` interface — need `hazard_ratio`, `hr_ci_lower`, `hr_ci_upper`, `n_samples`)

## Implementation

### New Component: ForestPlot.tsx

Create `frontend/src/components/ForestPlot.tsx`:

```tsx
interface ForestPlotProps {
  gene: GeneSurvival  // from chatSlice types
}

// Layout:
// Title: "Forest Plot: TP53 — Hazard Ratio Across Datasets"
//
// SVG-based layout (use plain SVG for precise control):
// Y-axis: dataset names (each dataset = one row), "Pooled" at bottom
// X-axis: HR values on log scale (0.5, 1.0, 2.0, 4.0)
// Each row: [dataset label left] | [square at HR point] | [horizontal error bar (CI)] | [HR text right]
// Pooled row: [Pooled label] | [diamond shape at pooled HR] | [CI error bar] | [pooled HR text]
// Vertical reference line at HR=1 (gray dashed)
// Color: red if HR > 1, blue if HR < 1

// Pooled estimate (inverse variance weighting):
const computePooledHR = (datasets: GeneDatasetResult[]) => {
  const valid = datasets.filter(d => d.hazard_ratio && d.hr_ci_lower && d.hr_ci_upper)
  if (valid.length === 0) return null
  const weights = valid.map(d => {
    const se = (Math.log(d.hr_ci_upper!) - Math.log(d.hr_ci_lower!)) / (2 * 1.96)
    return 1 / (se * se)
  })
  const totalWeight = weights.reduce((a, b) => a + b, 0)
  const pooledLogHR = valid.reduce((sum, d, i) => sum + weights[i] * Math.log(d.hazard_ratio!), 0) / totalWeight
  const pooledSE = Math.sqrt(1 / totalWeight)
  return {
    hr: Math.exp(pooledLogHR),
    ci_lower: Math.exp(pooledLogHR - 1.96 * pooledSE),
    ci_upper: Math.exp(pooledLogHR + 1.96 * pooledSE),
    n_total: valid.reduce((sum, d) => sum + (d.n_samples ?? 0), 0)
  }
}
```

SVG layout constants:
```typescript
const SVG_WIDTH = 600, SVG_HEIGHT_PER_ROW = 30, LABEL_WIDTH = 180, PLOT_START = 200
const HR_RANGE = [0.25, 6]  // log scale
const xScale = (hr: number) => PLOT_START + (Math.log(hr) - Math.log(HR_RANGE[0])) / (Math.log(HR_RANGE[1]) - Math.log(HR_RANGE[0])) * 300
```

### Update AnalysisResultsDisplay.tsx

Add 4th tab "Forest":
```tsx
// In tabs array:
{ id: 'forest', label: 'Forest Plot' }

// Add gene selector state:
const [selectedForestGeneId, setSelectedForestGeneId] = useState<string | null>(null)
const selectedForestGene = results?.common_genes.find(g => g.gene_id === selectedForestGeneId)
  ?? results?.common_genes[0]  // default: top gene

// In Forest tab content:
<div className="mb-3">
  <label className="text-xs text-gray-600 mr-2">Gene:</label>
  <select value={selectedForestGeneId ?? ''} onChange={e => setSelectedForestGeneId(e.target.value)}
    className="text-sm border rounded px-2 py-1">
    {results?.common_genes.slice(0, 20).map(g => (
      <option key={g.gene_id} value={g.gene_id}>{g.gene_symbol}</option>
    ))}
  </select>
</div>
{selectedForestGene && <ForestPlot gene={selectedForestGene} />}
```
