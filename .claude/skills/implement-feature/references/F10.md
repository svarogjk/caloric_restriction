# F10 — Gene Batch Input Mode

**Size**: M | **Priority**: 10

## Problem

Common pharma/biotech workflow: "I have 20 candidate genes from my RNA-seq experiment — which ones have survival relevance?" Currently requires 20 separate queries. Batch mode is a qualitative workflow improvement for the most important user segment.

## Files to Read First

- `backend/app/models/request_models.py` (`AnalysisRequest` model)
- `backend/app/services/geo_survival_workflow_orchestrator.py` (full `analyze_query` method — where to add gene filtering)
- `backend/app/services/survival_analysis_service.py` (find the gene analysis loop — where to apply the filter)
- `frontend/src/components/chat/ChatContainer.tsx` (settings panel structure)
- `frontend/src/store/chatSlice.ts` (analysis settings state)

## Implementation

### Backend: Request Model

`backend/app/models/request_models.py`:
```python
class AnalysisRequest(BaseModel):
    ...  # existing fields unchanged
    gene_list: Optional[List[str]] = Field(
        default=None,
        description="Optional list of gene symbols to restrict analysis to (batch mode). "
                    "When provided, only these genes are checked for survival associations."
    )

    @field_validator('gene_list')
    @classmethod
    def validate_gene_list(cls, v: Optional[List[str]]) -> Optional[List[str]]:
        if v is None:
            return v
        cleaned = [g.strip().upper() for g in v if g.strip()]
        if len(cleaned) > 500:
            raise ValueError("gene_list must contain at most 500 gene symbols")
        if len(cleaned) == 0:
            return None  # treat empty list as no filter
        return cleaned
```

### Backend: Survival Service Filter

`backend/app/services/survival_analysis_service.py` — Add `gene_filter` parameter:
```python
async def analyze_survival(
    self,
    loaded_data: LoadedGEOData,
    # ... existing params ...
    gene_filter: Optional[set[str]] = None
) -> SurvivalAnalysisResult:
    expression = loaded_data.expression_matrix

    if gene_filter:
        # Filter columns to only those matching gene symbols in gene_filter
        matching_cols = [col for col in expression.columns
                         if col.upper() in gene_filter or col in gene_filter]
        if not matching_cols:
            self.logger.warning(f"No matching genes found in dataset for batch mode filter")
            return SurvivalAnalysisResult(...)  # empty result
        expression = expression[matching_cols]
        self.logger.info(f"Batch mode: {len(matching_cols)}/{len(gene_filter)} genes found in dataset")

    # ... rest of existing survival analysis code ...
```

```bash
r = AnalysisRequest(query='test', gene_list=['TP53', 'BRCA1'])

cd frontend && npx tsc --noEmit && npm run build
```

Manual:
- Open settings → enter "TP53\nBRCA1\nMYC" in Candidate Genes → run analysis
- Results contain only TP53, BRCA1, MYC (or fewer if not found in datasets)
- Clear gene list → run again → all genes returned (normal behavior)
- Enter 501 genes → validation error in API response
